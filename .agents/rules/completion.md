# Automatický commit, push a deploy po dokončení úlohy

- Po úspešnom dokončení akejkoľvek úlohy v repozitári `books.polascin.net` (po overení kódovania, dát a úspešnom zbehnutí testov) vždy automaticky vykonaj commit všetkých zmien, push do vetvy `main` a over produkčné nasadenie (deploy).
- Tento krok vykonaj bez čakania na dodatočnú výzvu používateľa.
