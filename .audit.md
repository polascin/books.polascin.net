# Books Audit – opakovaný komplexný audit

## Popis projektu

Projekt **books.polascin.net** je PHP knižný katalóg Dr. Lubomíra Polaščína (PHP 8.x + MySQL/MariaDB). Obsahuje:

- Hlavnú stránku (`index.php`) — ex libris karta, prepojenia na katalóg a O autorovi
- Katalóg kníh (`catalog.php`) — kompletný prehľad kníh s vyhľadávaním a filtráciou podľa kategórie
- Stránku O autorovi (`about.php`) — bio, JSON-LD Person schéma, externé prepojenia
- Ochranné dokumenty (`privacy.php`) — Privacy Policy + právny disclaimer (noindex)
- Databázový setup (`setup_db.php`) — CLI-only skript na inicializáciu databázy (blokovaný z webu)
- Zdieľané PHP includes (`includes/`) — `header.php`, `footer.php`, `functions.php` (blokované z webu)
- Dáta (`data/`) — `books.json` záložný zdroj kníh (blokovaný z webu)
- Aktíva (`assets/`) — CSS (`style.css`), JS (`script.js`), obrázky (`author.png`, favicons)
- Bezpečnostný súbor (`.htaccess`) — HTTP hlavičky, blokovanie `setup_db.php`, `includes/`, `.git/`, `.env`
- SEO infraštruktúru (`robots.txt`, `sitemap.xml`, JSON-LD, Open Graph, Twitter Card, canonical URL)
- Front-end build — lokálne buildovaný Tailwind (`assets/css/tailwind.css`, pin 3.4.17) a self-hostované fonty (`assets/fonts/*.woff2` + `assets/css/fonts.css`); **žiadne CDN tretích strán** (Cinzel, Playfair Display, Noto Sans Glagolitic)
- Node build tooling (`package.json`, `tailwind.config.js`, `tools/tailwind.src.css`, `tools/fetch-fonts.mjs`) — nenasadzuje sa, výstupy sú commitnuté
- CI/CD (`.github/workflows/secret-scan.yml`) — skenovanie secrets pri každom push/PR
- Trunk (`.trunk/trunk.yaml`) — prettier, markdownlint, trufflehog, oxipng, git-diff-check
- Lokálne git hooks (`hooks/`) — pre-commit/pre-push skenovanie secrets (len lokálne)
- `.env` — databázové prihlasovacie údaje, `SITE_URL` (nikdy v gite, chránené `.gitignore`)

## 🎯 Cieľ auditu

Komplexná technická správa a kontinuálna optimalizácia projektu books.polascin.net. Audit vykonáva hĺbkovú analýzu PHP/HTML/CSS/JS kódu, audituje bezpečnosť databázovej vrstvy (PDO prepared statements, SQL injection, XSS via `htmlspecialchars`), overuje blokovanie chránených súborov cez `.htaccess`, spúšťa **Trunk** linting a formátovanie, kontroluje SEO integritu a štruktúrované dáta, audituje prístupnosť (WCAG 2.1), responzívny dizajn a výkonnostné charakteristiky. Vykonáva jazykovú korektúru anglických textov.

Opakované behy auditu riadi [`.doaudit.md`](.doaudit.md) — ten definuje cyklus (audit → oprava → overenie → zápis) a odkazuje späť na tento kontrolný zoznam.

## 📋 Primárne úlohy

### 1. Bezpečnostný audit PHP

- **SQL Injection ochrana:**
  - Všetky SQL dotazy prechádzajú cez PDO prepared statements (`$pdo->prepare()` + `execute()`)
  - Overenie, že priama interpolácia premenných do SQL (`"SELECT * FROM books WHERE id = $id"`) nie je prítomná
  - `PDO::ATTR_EMULATE_PREPARES => false` — native prepared statements
  - `PDO::ERRMODE_EXCEPTION` — výnimky pri chybách (nie tiché zlyhania)
  - Overenie `getBooks()` v `functions.php` — statický dotaz, žiadne user-supplied parametre

- **XSS ochrana:**
  - Všetky výstupy z databázy/JSON prechádzajú cez `esc_html()` (`htmlspecialchars($s, ENT_QUOTES, 'UTF-8')`)
  - Overenie v `catalog.php` — `data-title`, `data-author`, `data-category` atribúty na `<article>`
  - Overenie `safeUrl()` funkcie — `FILTER_VALIDATE_URL` + whitelist schém (len `http`/`https`)
  - Kontrola `header.php` — meta tagy, JSON-LD výstup (`json_encode` vs. priamy výpis)
  - Cookie banner (`footer.php`) — text neobsahuje dynamické dáta z URL/DB

- **File Inclusion bezpečnosť:**
  - `require_once __DIR__ . '/includes/functions.php'` — absolútna cesta, žiadna dynamická inkúzia
  - Žiadne `include($_GET['page'])` ani podobné vzory
  - `setup_db.php` — SAPI check: `php_sapi_name() !== 'cli'` → 403 Forbidden
  - `loadEnv()` — overenie, že `.env` nie je prístupný z webu (`.htaccess` blok)

- **Bezpečnostné hlavičky v `.htaccess`:**
  - Prítomnosť a správnosť: `X-Frame-Options`, `X-Content-Type-Options`, `HSTS`, `Referrer-Policy`, `Permissions-Policy`, `Cross-Origin-Opener-Policy`, `X-Permitted-Cross-Domain-Policies`
  - **`Content-Security-Policy`** — bez `'unsafe-inline'` a bez cudzích originov. Každý nový inline `<script>`, inline `style="…"` atribút alebo externý zdroj musí byť najprv deklarovaný v politike, inak ho prehliadač zablokuje. `img-src` musí ponechať `data:` kvôli SVG šumu v `.paper-texture`.
  - `Cache-Control` — dlhá platnosť pre `/assets/` (fonty `immutable`), `no-cache` pre `.php`; platí len dovtedy, kým CSS/JS chodia cez `assetUrl()` s `?v=<mtime>`
  - `Header unset X-Powered-By` — skrytie PHP verzie
  - `Options -Indexes`, `ServerSignature Off`
  - `<Files "setup_db.php">` — blokovanie priameho webového prístupu
  - `<FilesMatch "\.(env|pem|key|...)">` — blokovanie citlivých prípon
  - `RedirectMatch` + `RewriteRule` — blokovanie `includes/`, `data/`, `tools/`, `hooks/`, `.git/`, `.claude/`, `.vscode/`, `.agents/`, `.github/`

- **`.gitignore` kontrola:**
  - `.env`, `.env.*` — databázové prihlasovacie údaje nie sú v gite
  - `*.pem`, `*.key`, `*.p12`, `*.pfx` — kryptografické súbory
  - `.claude/` — lokálna konfigurácia agenta
  - `vendor/` — PHP závislosti (ak budú pridané)
  - Overenie, že samotný `.env` súbor nie je v git trackingu

### 2. Audit databázovej vrstvy

**Statická analýza `setup_db.php`:**

- CLI-only guard (`php_sapi_name() !== 'cli'`) — správnosť a úplnosť
- `CREATE TABLE IF NOT EXISTS books` — schéma: typy stĺpcov, `NOT NULL` constraints, `ENGINE=InnoDB`, `utf8mb4_unicode_ci`
- `SHOW COLUMNS FROM books LIKE 'url'` — migračná logika pre chýbajúce stĺpce
- Zálohovanie z JSON (`data/books.json`) — `file_get_contents()` + `json_decode()` + PDO `prepare()`/`execute()`
- Ošetrenie chýb: `try/catch PDOException`, `error_log()`, žiadne odhalenie citlivých detailov v output

**Analýza `functions.php`:**

- `getDbConnection()` — PDO options, DSN konštrukcia bez XSS rizika, `error_log()` namiesto `die()` s detailmi
- `getBooks()` — fallback na JSON pri zlyhání DB (resilience), statický `SELECT *`
- `esc_html()` — správnosť, pokrytie všetkých výstupov
- `safeUrl()` — whitelist schém, `FILTER_VALIDATE_URL`, ochrana pred `javascript:` a `data:` URL
- `excerptText()` — `strip_tags()`, `mb_strlen()`/`mb_substr()` pre Unicode bezpečnosť
- `loadEnv()` — `.env` parser: ochrana pred path traversal, správne parsovanie quotovaných hodnôt

### 3. Overenie blokovania chránených súborov

> Toto je jediná sekcia, ktorú **nestačí overiť čítaním konfigurácie** — pravidlo môže byť v `.htaccess` správne a napriek tomu neúčinné (chýbajúci modul, súbor sa nenasadil, prepis na úrovni servera). Vždy over `curl -I` proti produkcii.

- **`setup_db.php`:** `<Files "setup_db.php"> Require all denied` — HTTP 403 pri webovom prístupe
- **`includes/`:** vlastný `includes/.htaccess` s `Require all denied` + poistka v koreňovom `.htaccess`
- **`data/`:** vlastný `data/.htaccess` — `books.json` nesmie byť stiahnuteľný (bol verejný do behu #1)
- **`tools/`, `hooks/`:** `.deployignore` ich nenasadzuje, blokovanie je druhá vrstva
- **`.env`:** `<FilesMatch "\.(env|...)">` — `.env` súbor je blokovaný
- **Citlivé adresáre:** `.git/`, `.claude/`, `.vscode/`, `.agents/`, `.github/` cez `RewriteRule`
- **robots.txt kontrola:** `Disallow: /setup_db.php`, `Disallow: /includes/`, `Disallow: /data/`, `Disallow: /.git/`

### 4. HTML a PHP audit

- Validita HTML5 štruktúry (`<!DOCTYPE html>`, sémantické elementy v `header.php`/`footer.php`)
- Prítomnosť `lang="en"` na `<html>` elemente
- `alt` atribúty na všetkých `<img>` elementoch (`author.png`, favicons)
- `aria-label`, `aria-hidden`, `role` na interaktívnych elementoch
- `rel="noopener noreferrer"` na všetkých `target="_blank"` odkazoch
- Konzistentnosť `id` atribútov — duplicity, referencie v kotvách (`#book-{id}`, `#legal-disclaimer`)
- Cookie banner (`footer.php`) — `role="dialog"`, `aria-live="polite"`, `aria-label`
- Navigácia (`header.php`) — `<nav aria-label="Main Navigation">`, správna štruktúra `<ul>`
- Validita e-mailových adries (`mailto:lubomir@polascin.net`)
- `<head>` — len lokálne `<link rel="stylesheet">` na `tailwind.css`, `fonts.css` a `style.css` v tomto poradí; **žiadny externý `<script>` ani `<link>` na cudzí origin** (regresia by odhalila IP návštevníka)
- PHP chybové výstupy — `display_errors` by malo byť OFF v produkcii

### 5. SEO optimalizácia

- **Meta tagy:** `description`, `author`, `robots`, `theme-color` na každej stránke
- **`pageRobots`:** `max-image-preview:large`, `max-snippet:-1` na indexovaných stránkach
- **`privacy.php`:** `noindex, follow` — správnosť
- **Canonical URL:** `buildAbsoluteUrl()` — konzistentnosť naprieč stránkami, `/index.php` → `/`
- **Open Graph:** `og:type`, `og:title`, `og:description`, `og:url`, `og:image`, `og:locale`, `og:site_name`
- **Twitter Card:** `twitter:card`, `twitter:title`, `twitter:description`, `twitter:image`, `twitter:url`
- **JSON-LD (Schema.org):**
  - `index.php` — `WebSite` + `CollectionPage` schémy
  - `catalog.php` — `CollectionPage` + `ItemList` s `Book` entitami (title, author, isbn, inLanguage, datePublished)
  - `about.php` — `Person` schéma (name, alternateName, jobTitle, sameAs, knowsAbout, image)
  - Validita a bezpečnosť výstupu: `json_encode(… | JSON_HEX_TAG | …)`. Bez `JSON_HEX_TAG` by názov knihy obsahujúci `</script>` uzavrel element a vpustil do stránky ľubovoľné značky.
- `<link rel="canonical">` a `og:url` sa odvodzujú zo `$_SERVER['SCRIPT_NAME']`, nikdy z `PHP_SELF` — pri zapnutom `PATH_INFO` nesie `PHP_SELF` reťazec od návštevníka.
- `ItemList` — `position` musí byť súvislé, aj keď sa nejaký záznam preskočí
- **`sitemap.xml`:** aktuálnosť `lastmod`, správnosť `changefreq` a `priority`, prítomnosť všetkých verejných stránok
- **`robots.txt`:** blokovanie scrapers (SemrushBot, AhrefsBot, MJ12bot, DotBot, BLEXBot, PetalBot), `Crawl-delay: 10`, odkaz na sitemap

### 6. Prístupnosť (Accessibility / WCAG 2.1)

- Kontrast farieb — `bg-slate-900 text-paper` v headeri/footeri, text na `paper-texture` pozadí
- Klávesová navigácia — fokus viditeľný (Tailwind `focus:ring-2`, globálny `:focus-visible` v `style.css`), tab-order logický
- Preskočenie na obsah — `.skip-link` v `header.php` mieri na `#main-content` (WCAG 2.4.1)
- **Nič skryté nesmie zostať v tab-orderi.** Cookie banner sa skrýva atribútom `hidden`, nie iba `translate-y-full` — posunutý mimo obrazovku ostáva fokusovateľný aj čitateľný pre čítačku obrazovky.
- Dynamické zmeny obsahu sa oznamujú — `role="status"` na počítadle výsledkov v `catalog.php`
- Opakujúce sa odkazy („View Online" na každej karte) majú rozlišujúci `aria-label` s názvom knihy
- `target="_blank"` odkazy oznamujú otvorenie v novej karte (v `aria-label`)
- Dekoratívne emoji (🌐) sú v `<span aria-hidden="true">`
- `prefers-reduced-motion: reduce` — CSS vypína prechody a `scroll-behavior`, `script.js` číta tú istú preferenciu cez `matchMedia` a vynecháva oneskorenia
- `aria-label` na vyhľadávacom poli (`id="search-books"`)
- `<label for="category-filter">` — správne priradenie k `<select>`
- SVG ikony — `aria-hidden="true"` (search ikona, prázdny katalóg ikona, ex libris SVG)
- Cookie banner tlačidlá — `aria-label="Reject all non-essential cookies"`, `aria-label="Accept all cookies"`
- Tlačidlá `min. 44×44 px` touch target — overenie výšky/šírky v Tailwind triedach
- Pätička `role="contentinfo"` — prítomnosť
- Latinské/grécke/hlaholské texty — `lang` atribúty (`lang="la"`, `lang="grc"`, `lang="cu"`)

### 7. Responzívny dizajn

- Overenie `md:` breakpointov v Tailwind triedach naprieč všetkými stránkami
- Kontrola pretekania obsahu na úzkych obrazovkách (320px–480px)
- Navigácia (`header.php`) — `flex justify-between` + `space-x-6` — mobile zobrazenie
- Ex libris karta (`index.php`) — pevná šírka `w-80` — správanie na mobiloch
- Katalógová mriežka (`catalog.php`) — `grid-cols-1 md:grid-cols-2 xl:grid-cols-3` — škálovanie
- Toolbar vyhľadávania — `w-full md:flex-1`, `w-full md:w-64` — responzívne rozloženie
- Catalog hero grid — `catalog-hero-grid` CSS trieda (custom v `style.css`)
- Cookie banner — `flex-col md:flex-row` — správne zobrazenie na mobiloch

### 8. Výkon a načítanie

- Tailwind bundle — commitnutý `assets/css/tailwind.css` musí zodpovedať zdrojom (`npm run build:css` + `git diff --quiet`); CI pri drifte zlyhá
- Fonty — `@font-face` v `assets/css/fonts.css` s `font-display: swap`, `.woff2` z vlastného originu; žiadny `preconnect` na cudzie domény
- `loading="lazy"`, `decoding="async"` a `width`/`height` na `author.png` v `about.php` (bez rozmerov vzniká layout shift)
- `<script src="…/script.js">` v pätičke (správna poloha — po obsahu)
- Cache-busting — všetky CSS/JS/obrázkové cesty cez `assetUrl()` (`?v=<mtime>`). Natvrdo napísaná cesta na `/assets/…` obchádza cache-busting a s dlhým `Cache-Control` sa k návštevníkovi nová verzia nedostane.
- Veľkosť `tailwind.css` — purge podľa `content` globov v `tailwind.config.js`; trieda skladaná za behu z reťazca sa vypurguje, ak nie je v globoch alebo v safelist
- `site.webmanifest` — správnosť a kompletnosť pre PWA

### 9. Integrita odkazov a sieť

- Overenie externých odkazov v `about.php` — Amazon author pages, `polascin.net`, `polascin.com`, `nephrosite.polascin.net`
- Konzistentnosť `sameAs` v JSON-LD `Person` schéme s odkazmi na stránke
- `rel="noopener noreferrer"` na všetkých `target="_blank"` odkazoch
- Google Search fallback URL v `catalog.php` — `rawurlencode()` správnosť
- Pätičkové prepojenia — `privacy.php`, `privacy.php#legal-disclaimer` — ciele existujú
- Navigačné prepojenia — `index.php`, `catalog.php`, `about.php` — konzistentnosť

### 10. Cookie Consent (GDPR)

- Cookie banner (`footer.php`) — text informuje o cookies, odkaz na `privacy.php`
- `privacy.php` — obsah Sekcie 3 je v súlade s faktickým správaním cookies
- `localStorage` kľúč pre consent — konzistentnosť v `assets/js/script.js`
- Banner sa nezobrazí opäť po udelení/odmietnutí súhlasu — overenie logiky v `script.js`
- GDPR — žiadne analytics/tracking bez explicitného súhlasu

### 11. Trunk — linting a formátovanie

> **Stav:** `.trunk/trunk.yaml` v tomto repozitári zatiaľ **nie je** — nasledujúce je cieľová konfigurácia pre prípad, že sa Trunk zavedie. Do tej doby platia reálne projektové kontroly zo sekcie „Nástroje a technológie" nižšie a z [`.doaudit.md`](.doaudit.md): `php -l`, `node --check`, `npx prettier --check`, `npm run build:css` (drift Tailwind buildu) a `tools/quality.ps1` (PHPStan + PHP-CS-Fixer).

**Nakonfigurované nástroje:**

| Nástroj          | Verzia | Typ           | Čo kontroluje                                                       |
| ---------------- | ------ | ------------- | ------------------------------------------------------------------- |
| `prettier`       | 3.8.3  | Formátovanie  | PHP, HTML, CSS, JS, JSON, Markdown — jednotný štýl                  |
| `markdownlint`   | 0.48.0 | Lint          | `.audit.md`, `.doaudit.md`, `README.md` — štruktúra a štýl Markdown |
| `trufflehog`     | 3.95.3 | Bezpečnosť    | Skenovanie secrets a citlivých reťazcov v kóde aj histórii          |
| `oxipng`         | 10.1.1 | Optimalizácia | Bezztrátová kompresia PNG obrázkov (author.png, favicons)           |
| `git-diff-check` | —      | Kvalita       | Trailing whitespace, merge-conflict markery                         |

**Ignorované cesty (definované v `.trunk/trunk.yaml`):**

- `vendor/**` — PHP závislosti tretích strán
- `data/**` — dátové súbory (books.json — binárne/generované)

**Príkazy na spustenie:**

```bash
# Kontrola všetkých súborov (bez autoopravy)
trunk check

# Kontrola len zmenených súborov od posledného commitu
trunk check --diff

# Automatické formátovanie (prettier, oxipng)
trunk fmt

# Formátovanie len zmenených súborov
trunk fmt --diff

# Len secrets skenovanie
trunk check --filter=trufflehog

# Len markdown
trunk check --filter=markdownlint

# Len obrázky
trunk check --filter=oxipng
```

**Postup pri Trunk výstupe:**

1. Spustenie `trunk check --diff` na zmenených súboroch
2. Nálezy sa klasifikujú podľa nástroja: bezpečnostné (trufflehog) → 🔴, formátovacie (prettier) → 🟢
3. `trunk fmt --diff` aplikuje formátovanie automaticky (triviálna oprava)
4. Trufflehog nálezy sú vždy 🔴 a **vyžadujú manuálne posúdenie**
5. Výsledky sa zahrnú do štandardnej audit správy

### 12. CI/CD a Git hooks audit

- **`.github/workflows/secret-scan.yml`:** overenie patterns zhodnosti s lokálnymi hooks
- **`hooks/`:** lokálne pre-commit/pre-push hooks — prítomnosť a správnosť patterns
- **`.gitignore`:** `.env`, `.env.*`, `*.pem`, `*.key`, `*.p12`, `*.pfx`, `.claude/`, `vendor/`, `tools/*.phar`
- **`package-lock.json` musí byť commitnutý** a CI musí používať `npm ci`. Pri `npm install` bez lockfile môže tranzitívna závislosť zmeniť výstup buildu a kontrola „stale Tailwind bundle" zlyhá na nesúvisiacom pushi.
- **`deploy.yml` job `validate`:** `php -l` nad všetkými sledovanými PHP súbormi, `node --check`, kontrola driftu `assets/css/tailwind.css`
- Workflowy majú `permissions: contents: read` a `persist-credentials: false`
- Overenie, že `.env` nie je v git histórii (`git log --all -- .env`)

## ✅ Triviálne opravy

Bez explicitného súhlasu je možné **automaticky opraviť**:

- Preklepy a gramatické chyby v EN textoch
- Chýbajúci `alt` text na `<img>` elementoch
- Chýbajúci `rel="noopener noreferrer"` na `target="_blank"` odkazoch
- Nekonzistentné odsadenie (whitespace, formátovanie)
- Chýbajúce `aria-hidden="true"` na dekoratívnych SVG ikonách
- Aktualizácia `lastmod` v `sitemap.xml`
- Cache-busting verzie CSS/JS súborov

**Súhlas zadávateľa je nutný** pred:

- Zmenami databázovej schémy alebo PHP logiky
- Zmenami v cookie consent logike (`script.js`)
- Úpravami JSON-LD schémy (pridanie/zmena polí)
- Zmenami `.htaccess` pravidiel
- Zmenami ovplyvňujúcimi viacero súborov naraz
- Pridaním nových externých závislostí
- Akýmikoľvek zmenami `setup_db.php`

## ⚙️ Pracovný postup auditu

1. **Inicializácia:** Načítanie všetkých cieľových súborov
2. **Trunk check:** `trunk check --diff` — linting, secrets, git-diff-check
3. **Trunk fmt:** `trunk fmt --diff` — automatické formátovanie (prettier, oxipng)

## 🔐 Bezpečnostné pravidlá auditu

- Audit má prístup **na čítanie a zápis** pre automatické opravy triviálnych chýb
- Audit **nerobí commit ani push** — všetky zmeny ostávajú lokálne pre review (výnimkou je záverečný commit podľa [`.doaudit.md`](.doaudit.md), ak ho zadávateľ vyžiada)
- Audit **nespúšťa PHP kód** — iba statická analýza súborov; výnimkou je `php -l` (syntax lint) a `php setup_db.php` z CLI pri zmene schémy
- Audit **nespúšťa SQL dotazy** — iba analýza schémy a kódu
- Výstupy sú **v chate** a zapisujú sa ako „Beh #X" do tohto dokumentu — bez GitHub Issues/PR
- Audit rešpektuje vylúčenia zo sekcie „Vylúčené zo skenovania"
- `.env` súbor — audit ho môže čítať pre overenie štruktúry, **nikdy nevypisuje hodnoty** premenných

### Otvorené / na manuálne posúdenie

- **Trunk** (sekcia 11) — `.trunk/trunk.yaml` v repozitári nie je. Sekcia zostáva ako cieľový stav; reálne kontroly pokrýva `.doaudit.md`.
- **`preconnect`/`preload` fontov** — pri `unicode-range` rozdelených subsetoch hrozí dvojité stiahnutie. Neriešené zámerne; ak sa bude riešiť LCP, preloadovať len latinský subset Cinzelu.
- **Ikony v `site.webmanifest`** — najväčšia je 180×180. Pre plnú inštalovateľnosť PWA treba 192×192 a 512×512 (vrátane `maskable`); vyžaduje si nové obrázky, nie zmenu kódu.
- **Na serveri sú stále fyzicky prítomné súbory, ktoré tam nahral starý deploy hook** (`setup_db.php`, interné `.md`, CI konfigurácia, `tools/`, `hooks/`, `package-lock.json`, `phpstan.neon.dist`, `.prettierrc`, …). Všetky sú blokované cez `.htaccess` a `setup_db.php` má navyše CLI guard, takže riziko je nízke — ale ich odstránenie zo servera je ručný krok, ktorý oprava hooku spätne neurobí.
- **`DEPLOY_*` secrets nie sú nastavené**, takže CI deploy je nečinný (nález 36). Kým sa nedoplnia, produkciu mení len lokálny post-commit hook — čo znamená, že nasadiť môže len ten, kto má lokálne `~/.ssh/books_deploy`.
- **CSP je prísna zámerne.** Čokoľvek nové s inline `<script>`, inline `style="…"` alebo cudzím originom treba najprv deklarovať v `.htaccess`, inak to prehliadač ticho zablokuje.
- **Výnimka pre `.env.example` v secret scanningu** je zúžená na obsahovú kontrolu jedného konkrétneho súboru. Ak by doň niekto vložil skutočné heslo, hooky ho nezachytia — pri zmenách v `.env.example` platí, že hodnoty musia zostať zástupné.
